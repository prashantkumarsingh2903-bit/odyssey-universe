# 🌌 ODYSSEY — 3D Black Hole Knowledge Universe

> **“Nothing I learn disappears. It becomes part of my universe.”**

ODYSSEY is an interactive 3D personal knowledge universe where ideas, learnings, and daily reflections are represented as a living gravitational cosmos orbiting a physically-simulated **Black Hole** (Second Brain). It features real-time AI computer vision hand-gesture tracking for hands-free spatial exploration.

![ODYSSEY Preview](https://raw.githubusercontent.com/prashantkumarsingh2903-bit/odyssey-universe/main/preview.png) *(or live demo link below)*

---

## ✨ Features

- 🕳️ **Hyper-Realistic Raymarched Black Hole**:
  - General relativity gravitational lensing (light bending).
  - Doppler redshift / blueshift on relativistic accretion disk.
  - Dynamic event horizon, photon ring, and swirling plasma accretion disk.
- 🪐 **Living Knowledge Graph & Orbitals**:
  - Memory nodes categorized by *Idea, Goal, Memory, Insight, Reflection*.
  - Gravitational orbits based on gravity mass, importance, and decay rates.
  - Interactive bezier gravitational connection links.
- 🖐️ **AI Hand Gesture Holographic HUD**:
  - Powered by `@mediapipe/tasks-vision` real-time neural hand tracking.
  - **Open Palm / Move**: Orbit and pan the camera spatially.
  - **Pinch (Index + Thumb)**: Dynamic zoom in/out with velocity damping.
  - **Closed Fist**: Gravitational surge & time dilation effect.
  - **Victory / Peace (✌️)**: Instant reset of camera orientation.
  - Real-time cybernetic hand skeleton visualizer and gesture telemetry HUD.
- 🎛️ **Cinematic UI**:
  - Knowledge node inspector & details drawer.
  - Dynamic insight analysis panel.
  - Quick capture modal for feeding new thoughts into the accretion disk.

## 🚀 Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **3D / Shaders**: Three.js, React Three Fiber (`@react-three/fiber`), `@react-three/drei`, Custom GLSL Raymarching Shaders
- **Vision AI**: Google MediaPipe Tasks Vision (`@mediapipe/tasks-vision`)
- **Animation & Styling**: Tailwind CSS v4, Framer Motion, Lucide Icons
- **State Management**: Zustand

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/prashantkumarsingh2903-bit/odyssey-universe.git

# Navigate into directory
cd odyssey-universe

# Install dependencies
npm install

# Start local development server
npm run dev
```
